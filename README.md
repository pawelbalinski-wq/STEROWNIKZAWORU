# STEROWNIK ZAWORU
Prosty sterownik pogodowy zaworu 3D mieszacza ogrzewania podłogowego na Arduino Uno.
Zamierzeniem jest skonstruowanie sterownika jak najprostszego w obsłudze dla nietechnicznej osoby. 
Aktualnie używam sterownika TECH, sam się gubię w jego obsłudze i bardzo łatwo go "rozregulować".
