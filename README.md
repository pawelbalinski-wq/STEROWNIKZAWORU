# STEROWNIK ZAWORU
Prosty sterownik pogodowy zaworu 3D mieszacza ogrzewania podłogowego na Arduino Uno.
Zamierzeniem jest skonstruowanie sterownika jak najprostszego w obsłudze dla nietechnicznej osoby. 
Aktualnie używam sterownika TECH, owszem, jest bardzo uniwersalny, 1000 parametrów w 50 różnych menu... a ja mam 60 lat i za rok znów nie będę pamietał co gdzie się ustawia. A w razie czego małżonka nie włączy ogrzewania.
Pierwszy raz w życiu usiłuję napisać jakiś program, a właściwie robi to za mnie AI.
