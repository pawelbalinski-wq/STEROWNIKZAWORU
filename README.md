# STEROWNIK ZAWORU
Prosty sterownik pogodowy zaworu 3D mieszacza ogrzewania podłogowego na Arduino Uno.
Zamierzeniem jest skonstruowanie sterownika jak najprostszego w obsłudze dla nietechnicznej osoby. 
Aktualnie używam sterownika TECH, a że jest on bardzo uniwersalny - 1000 parametrów w 50 różnych menu... mam 60 lat i za rok znów nie będę pamietał co gdzie się ustawia.
Nie jestem informatykiem, nie znam angielskiego ale dziś mamy AI...
